# Captures d'écran

Emplacements attendus par le [README principal](../../README.md). Il suffit de déposer les images
ici sous ces noms de fichier, au format PNG, de préférence en 1440 px de large.

| Fichier               | Écran |
|-----------------------|-------|
| `connexion.png`       | Page de connexion |
| `paiement.png`        | Espace client : nouveau paiement et suivi du statut |
| `tableau-de-bord.png` | Analyste : tableau de bord en temps réel |
| `detail-alerte.png`   | Analyste : détail d'une alerte, avec les explications SHAP |
| `statistiques.png`    | Analyste : statistiques et performance du modèle |
| `administration.png`  | Administration : utilisateurs et règles métier |
